# raw/

Inbox for unprocessed material — chat transcripts, meeting notes, article
clippings — captured before it's been distilled into OKF concepts
(Karpathy-style capture stage).

This folder is **not** part of the OKF bundle proper: files here don't need
YAML frontmatter or a `type`, and nothing here should be linked to from a
finished concept. Once something is worth keeping, turn it into a real
concept elsewhere in the vault and remove (or archive) it from here.
